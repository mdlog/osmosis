i.

Reading that is almost easy, which is where learning happens.

1

Turn one dial

The dial sets how much of each page is in the language you're learning. At 10% you meet a sentence now and then. At 80% you're reading a foreign newspaper.

Spanish · A235%
2

One new word at a time

A sentence only switches if you'd understand almost all of it. Osmosis counts the new words against the words you know and prefers sentences with exactly one. Our code makes that choice, not the model.

Solo tiene cuatro vagones.One new word: vagones. Everything else you already know.
3

Hover when you're stuck

Hover a sentence to see the original and the new word. Linger, and Osmosis takes note. Click a word once you know it, and it stops being highlighted.

The check clears Osmosis's cache, translates a 24-sentence article in a real Chrome, and records every network request from the extension's service worker, where all page translation happens. To prove the recorder works, it also sends one deliberate request, and that one shows up.

iii.

Try it.

  1. Get the code and build itnpm install then npm run build. The README covers the Firebase setup.
  2. Load it in ChromeOpen chrome://extensions, turn on Developer mode, then Load unpacked and pick dist/extension.
  3. Choose your languageClick the Osmosis icon. Pick a language and level, and let Chrome download its on-device model.
  4. Read anything in EnglishNews, blogs, documentation. The dial sits in the corner.
